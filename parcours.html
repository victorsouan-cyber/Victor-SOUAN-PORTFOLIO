Choix technique du Portfolio

Pourquoi un site codé en HTML / CSS / JS sur GitHub Pages ?

Plutôt que d'utiliser un éditeur visuel générique (comme Google Sites ou Wix), j'ai choisi de coder mon portfolio sous Visual Studio Code et de l'héberger sur GitHub Pages. Ce choix offre une arborescence claire sans publicité ni limitation de mise en page, un chargement rapide sur ordinateur comme sur mobile, et me permet de mettre directement en pratique mes compétences en programmation et gestion de versions.
